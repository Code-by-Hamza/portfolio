# Hamza Akhlaq: Portfolio

Personal developer portfolio built with React, Vite and plain CSS (no UI libraries).

## Run

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run lint     # oxlint
```

## Edit content

All text, links, skills and projects live in `src/data/site.js`.
Empty `email` / `linkedin` values are hidden automatically, so fill them in when ready.
Design tokens (colours, spacing, type) are in `src/styles/variables.css`.
